# TLCTC v2.3 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce the authoritative TLCTC v2.3 core as a matched pair — a machine-readable framework JSON and a self-contained core paper — by consolidating finalized v2.1 content under a clean version number, adding no new normative content.

**Architecture:** Two new files authored together. `tlctc-framework.v2.3.json` is the immutable Layer-1 dictionary (10 clusters, 10 axioms, R-* rules including v2.1 extensions). `tlctc-v2.3-core.md` is the human-readable paper (thought experiment, definitions, notation, concise glossary, references). Old v2.0 files are untouched; everything else (application doc, integration doc, version-string cleanup, Scholar/DOI pipeline) is deferred to follow-on specs.

**Tech Stack:** JSON (JSON Schema draft-07), Markdown. Validation via Node 24 + `ajv`/`ajv-formats`. Verification via `grep`/`rg`.

**Spec:** `docs/superpowers/specs/2026-06-07-tlctc-v2.3-core-design.md`
**Branch:** `v2.3-core` (off `main`). **No push / merge / PR / tag-push until owner approves.** Local commits only.

---

## Note on format (read first)

This is a **content-consolidation** plan, not a code feature. Two adaptations of the standard TDD task shape:

- The **JSON task** has fully-specified content (it is small and fully determinable) — treat it like code.
- The **paper-section tasks** cannot inline thousands of words of final prose. Each instead gives: the **exact source** to consolidate from, **what to keep/cut**, a **length target**, and a concrete **verification check** (schema validation, `grep` for required headers/terms, traceability). The "test" for a content section is a grep/structural assertion, run and confirmed before commit.

The hard constraint everywhere: **consolidation, not invention.** If a section seems to need a rule/definition that is not already in v2.1 source (`tlctc-v2.0-whitepaper.md`, `tlctc-framework.v2.0.json`, `CLAUDE.md`), **STOP and ask the owner** — do not author new normative content.

```js
// Validates a TLCTC framework JSON against the Layer-1 schema.
// Usage: node scripts/validate-framework.js <schema.json> <data.json>
const fs = require("fs");
const Ajv = require("ajv");
const addFormats = require("ajv-formats");

const [, , schemaPath, dataPath] = process.argv;
const schema = JSON.parse(fs.readFileSync(schemaPath, "utf8"));
const data = JSON.parse(fs.readFileSync(dataPath, "utf8"));

const ajv = new Ajv({ allErrors: true, strict: false });
addFormats(ajv);

const validate = ajv.compile(schema);
if (validate(data)) {
  console.log("VALID");
} else {
  console.log("INVALID");
  console.log(JSON.stringify(validate.errors, null, 2));
  process.exit(1);
}
```
