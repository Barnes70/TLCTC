# Axiom II

All system interactions, networked or intra-system, can be abstracted as client-server interaction.

> v2.4 clarification: a network is not a precondition. A syscall, hypercall, or IPC call establishes the same caller-called relation as a remote protocol exchange, so intra-system privilege interfaces are inside the interaction model. Prior wording ('All networked systems') was read by some implementers as excluding them.
